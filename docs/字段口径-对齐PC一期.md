# 字段与统计口径 · 对齐 PC 一期

> 日期：2026-09-17  
> 真源：PC `原型-外卖` 运营商一期菜单（站点信息、换电柜/电池、换电单、用户、资金实收）。  
> 依据：decision-032 / 036 / 037 / 038。竞品字段不作为定义来源。

## 原则

1. **PC 一期有的**：APP 表单/统计用同一中文名、同一枚举、同一公式。
2. **PC 明确二期的**：APP 可浏览但标二期（远程运维、端口操作、电柜组成、场费电费）。
3. **竞品有、PC 一期没有的**：从统计/表单拿掉，或改成 PC 名称。
4. **APP 已拍板的交互**（一用户最新单、电柜 5 Tab、电池从订单进详情、图表 Tab）保留，只改字段名和口径。

## 统计

| 指标 | PC 一期定义 | APP 用法 |
|------|-------------|----------|
| 在线电柜 | `online === true` | 经营 KPI、设备统计柜机组 |
| 停用柜 | `deviceStatus === 停用` | 设备统计 |
| 通电 | `已通电` / `未通电` | 电柜列表/详情。列表：**已通电绿 / 未通电红** |
| 电柜在线 | `online === true` 为在线 | 列表：**在线绿 / 离线红**。未分配另标灰，不替代在线色 |
| 在线电池 | 有 `online` 用该字段；否则随所在柜在线 | 经营 KPI、设备统计 |
| 离线电池 | 总数 − 在线；或 `online=false` | 设备统计电池组 |
| 电池位置 | `自有电柜` / `其他运营商电柜` / `柜外` / `柜外-用户`；站点仅格口内展示 | 电池详情「位置」 |
| 在营站点 | 营业状态 `在营` | 经营 KPI「在线站点」= 在营且有在线柜 |
| 繁忙度 | 高：等待≥3 或占用≥85%；中：等待≥1 或≥60%；否则低。占用≈柜内电池/仓口 | 站点繁忙度 Tab |
| 换电高峰 | 成功换电按小时；≥当日峰值 65% 的连续小时合并 | 卡片「高峰」+「最忙时段」 |
| 套餐购买金额 | C 端实付 `Σ pay`，随今日/7日/30日 | 图表「套餐购买金额」 |
| 换电订单数 | 成功+失败换电单按日 | 图表「换电订单数」 |
| 活跃用户 | 去重骑手；排除退款/完结、服务已冻结/中途完结 | 图表「活跃用户」；KPI「有效*用户」= 未结束换电单 |
| 有效个人用户 | 未结束个人换电单去重（**含冻结中**）。KPI 展示 `N 人（冻结中：M 人）`，M⊆N。冻结期间不可换电、须未持电 | KPI |
| 有效渠道用户 | 未结束人天单去重（含待还电） | KPI |
| 告警电柜 | 柜体过温 / 换电柜离线 / 未正常弹电池 / 弹错格口 / 门禁异常 | 待办 Tab·警告、电柜详情·本柜告警（**不在设备统计**） |

**不做（PC 二期或竞品）：** 站点收入、用电量进经营 KPI、已售、火警/水浸、Package/Rent/Idle、短期/长期离线分档、日新增租用户、日实充用户。

## 经营统计 · 业务边界与时间边界（decision-036）

> 给开发对账用。原型 Mock 数字不必按此重算；正式环境必须按此。

### 1. 两层时间，不许混

| 层 | 作用对象 | 时间行为 |
|----|----------|----------|
| **快照** | 页顶 5 个 KPI；站点繁忙度的低/中/高、等待、格口占用、在线柜 | **此刻**。切自然月**不变** |
| **区间** | 图表 Tab 内趋势图 | 跟 **今日 / 近7日 / 自然月**（默认近7日；自然月才选年+月） |
| **自然日高峰** | 繁忙度卡「高峰」「最忙时段」 | **当天**成功换电分时。APP **不做** PC 总览那种历史「统计日」回放 |

时区：**Asia/Shanghai**。切日：**自然日 00:00:00 ≤ t < 次日 00:00:00**，不是滚动 24 小时。

| 筛选项 | 闭开区间 | 柱数 |
|--------|----------|------|
| 今日 | `[今日0点, 明日0点)` | 横轴 4 小时段（0–4 … 20–24） |
| 近7日 | 含今日共 7 个自然日 | 横轴 MM-DD，默认 09-11…09-17 |
| 自然月 | 所选年月的 `[当月1日 00:00, 次月1日 00:00)` | 月内按日抽样约 7 根 |

年份从 **2026** 起；演示环境当前年仅可选至 **9 月**，9 月柱仅到 **17 日**。未来日不出柱。

### 2. 业务主体

只统计 **当前登录运营商主体**（锂电快换 / `device_owner_id`）。不含下级、不含全网、不含其他运营商柜上的跨网业务。**页顶 KPI 与图表**：管理员与员工同为主体全量。**站点繁忙度列表**：员工仅 `siteIds` 指定站（decision-057）。

### 3. KPI 快照 · 计入 / 不计入

| 指标 | 计入 | 不计入 |
|------|------|--------|
| 在线站点 | 营业状态=`在营` **且** 该站至少 1 台柜 `online=true` 且设备状态≠停用 | 建设中、已停用；有柜全离线/全停用的在营站 |
| 在线电柜 | `online=true` **且** 设备状态≠停用 | 停用柜（即使遥测在线）；未分配站点的待投放柜默认离线 |
| 在线电池 | 电池 `online=true`；无该字段则随所在柜在线 | 柜外且定位离线 |
| 有效个人用户 | 未结束个人套餐单去重（服务中 **+ 冻结中**） | 已结束、中途完结、已退款完结 |
| 其中冻结中 | 有效个人里 `服务状态=已冻结` | 冻结须未持电；冻结日不计入活跃 |
| 有效渠道用户 | 未结束人天单去重（使用中 **+ 待还电**） | 已结束、离职回池 |

渠道用户本期 **不** 拆冻结括号（人天停权走待还电/无额度，不走个人套餐冻结）。

### 4. 图表同比（decision-047）

图表 Tab 内每张趋势图展示 **本期 + 同比** 双柱。同比 = **去年同期同月**（如 2026 年 9 月对 2025 年 9 月，同抽样日对齐）。柱顶数字仅标注本期。Mock 同比约为本期 72%–88%。

### 5. 图表区间 · 事件时点

| 图 | 事件时点 | 计入 | 不计入 |
|----|----------|------|--------|
| 套餐购买金额 | **支付成功时间** `paid_at` | C 端套餐/次卡 **实付 `pay`** | 退款出款、电池占用费、额度池采购、清分/提现；**本图不扣退款**（退款看资金页） |
| 换电订单数 | **换电结束时间** `completed_at` | **成功 + 失败** | 进行中 |
| 活跃用户 | 区间内至少 1 笔成功换电，或当日仍服务中且未冻结 | 去重骑手 | 已冻结、中途完结、退款/完结套餐；冻结日不算活跃 |
| 套餐新购 | `paid_at` | 支付成功的套餐/次卡订单数（含首次与复购） | 占用费、退款单、额度池采购 |
| 新增用户 | 该骑手在本主体 **首次** 套餐支付成功或人天开通的自然日 | 去重 | 解冻、复购、改号不另计新增 |

金额单位：人民币元，按支付成功入账，**不是**清分台账。

### 6. 站点繁忙度

| 项 | 边界 |
|----|------|
| 列表范围 | 当前主体有柜的站点（含专属站）；**员工**再按 `siteIds` 过滤；不按图表时间筛 |
| 繁忙度 | **实时**：等待人数 + 格口占用。高：等待≥3 或占用≥85%；中：等待≥1 或≥60%；否则低 |
| 占用 | ≈ 本站柜内电池 / 本站仓口总数 |
| 高峰 / 最忙 | **当天**成功换电；连续小时 ≥ max(2, ceil(当日峰值×65%)) 合并为高峰文案；最忙=峰值小时 |
| 不做 | 站点收入、用户主站、历史统计日回放、用电量 |

### 7. 有效 ≠ 活跃（防对错账）

- **有效**：此刻还有未结束权益（含冻结、待还电）。  
- **活跃**：选定区间里真正在换电/可用的人（剔除冻结）。  
- 故：有效个人 5（冻结中 1）时，活跃最多 4。

## 工作台经营摘要（decision-037 / 046）

首页三卡固定**今日**，不是经营页顶的 5 个快照 KPI。无时间筛；点整区进经营统计。历史趋势在经营统计图表 Tab 按 **今日 / 近7日 / 自然月** 切换（默认近7日）。

| 卡 | 对齐图表 | 计入 | 不计入 |
|----|----------|------|--------|
| 换电次数（次） | 换电订单数（今日） | `completed_at` 成功+失败 | 进行中 |
| 换电人数（人） | — | 今日**成功**换电骑手去重 | 失败单、未换电的服务中用户（故 ≠ 活跃用户） |
| 套餐收入（元） | 套餐购买金额（今日） | `paid_at` C 端实付 | 退款、占用费、额度池、清分 |

Mock：86 次 / 18 人 / 4,690 元。管理员与员工同数。`[待确认]` 正式环境员工是否按指定站点裁这三卡。

## 工作台用户 / 电池快照（decision-055）

固定**今日**或**此刻**快照，无时间筛。布局：用户 9 格（3×3）+ 电池 3 格（1×3）。

| 指标 | 时点 | 计入 | 不计入 |
|------|------|------|--------|
| 今日新增 | 今日 | 本主体**首次**套餐支付成功或人天开通，按骑手去重 | 解冻、复购、改号 |
| 今日续费 | 今日 | 已有未完结订单用户，今日**延长服务期**的支付 | 首次开通 |
| 3天内到期 | 此刻 | 个人套餐 `到期日 ∈ (今日, 今日+3]` 且未完结 | **渠道人天**、已逾期 |
| 3天未换电 | 此刻 | 有效用户中最后成功换电 >3 自然日（含从未换电） | **冻结中**、已完结 |
| 今日退租 | 今日 | 服务关系完结（订单已结束/退款完结），按骑手去重 | — |
| 今日退电 | 今日 | 完成还电动作的骑手，按骑手去重 | — |
| 已逾期 | 此刻 | 个人「到期仍持有电池」+ 人天「占用逾期」 | 与待办逾期队列同口径 |
| 总用户（有效） | 此刻 | **总数** = 有效个人 + 有效渠道；卡片副文案 **个人 X · 渠道 Y** | 已结束订单 |
| 冻结中 | 此刻 | 有效个人里 `服务状态=已冻结` | 渠道（人天不走冻结） |
| 电池总数 | 此刻 | 本主体台账在册电池 | — |
| 使用中 | 此刻 | 骑手持有 + 在柜可换（有电且可分配） | 离线、故障 |
| 空闲 | 此刻 | 未绑定订单、可分配电池 | 使用中、维修 |

Mock：新增 2 / 续费 5 / 3天内到期 3 / 未换电 6 / 退租 1 / 退电 2 / 逾期 4 / 总用户 10（个人 5·渠道 5）/ 冻结 1；电池 12 / 使用中 5 / 空闲 5（另 2 离线不计入三格）。

## 财务 · 运营商账户（decision-038）

只统计 **当前登录运营商主体** 的子商户。金额是清分净额，**不是** C 端套餐实付（那是首页「套餐收入」/ 用户支付记录）。

| 项 | 公式 / 边界 | 不计入 |
|----|-------------|--------|
| 已清分 | 支付成功即时入运营商子商户的净额累计 | 占用费、额度池采购、平台 1%、渠道佣金 |
| 已提现 | 提现工单状态=`已提现` 的金额合计 | 已驳回 |
| 冻结中 | `待审核` / `审核通过` / `处理中` 合计 | 已提现、已驳回 |
| 账户总金额 | 已清分 − 已提现（= 可提现 + 冻结中） | 已打到银行卡的钱 |
| 可提现 | 已清分 − 已提现 − 冻结中；不为负则取 0 | **一期不扣**本月融资待还（二期） |

**收款账户**（进件子商户 · 转出户）：基本不变。字段：收款开户银行、收款户名、商户号、门店号、用途、转出招行卡、托管协议。APP **只读**，不可变更。

**提现账户**（对公结算 · 转入户）：可单独维护。字段：开户名称、银行卡号、开户银行、开户支行、联行号（选填）。APP **变更对公** 对齐 PC 弹窗。

提现工单：转出=收款账户；转入=提现账户快照。有待审不可再提交；无待审可进发起页。

## 表单 / 列表字段

### 站点

类型：`配送站` / `写字楼` / `渠道专属`。状态：`在营` / `建设中` / `已停用`。  
组织地址：搜索 / 点地图 / **选择当前位置**（设备 WGS-84 → GCJ-02）。逆地理仍 Mock。拒绝定位权限不回填。

### 电柜

基础信息与 PC 详情同名。权属 `自有`；原「租赁」展示 `融资` 并标二期。**充电服务设置不在运营商 APP**，留 PC。  
改站：**先解绑再绑定**。已上站不能直接改到另一站。电池不随站绑定。

列表筛：站点下拉为**精确站名**；关键字对 SN / 站点名称 / 电柜名称做包含匹配。两套条件 AND。未分配用站点值「未分配站点」。

### 换电订单

卡片增加 **权益来源**：`个人套餐` / `渠道人天`。个人「套餐」用 SKU/型号文案。人天「电池型号」用 `modelLabel`。人天「今日资格」枚举与 PC 相同。

### 用户

展示：姓名、手机、身份证、**实名认证**（已实名/未实名）、**服务状态**、**电池押金**、**押金状态**、个人套餐、渠道额度、当前持有电池。  
**只读查号**，不可改手机号（平台处理）。  
拿掉竞品：紧急电话、性别、用户渠道、手机认证、认证方式。

**实名认证**由**平台**处理，不在运营商 APP。用户管理仅只读展示 `已实名` / `未实名`（来自平台同步）。

### 资金

Tab：套餐支付 / **逾期占用费** / 退款。占用费全额进运营商、不进清分。仍不做额度池采购列表。

### 电池详情

位置四档用 PC 名称。健康度 SOH%。遥控与定位仍为 APP 现场页，不回写 PC。
