## 3. 工作台

| ID | 验收项 | 通过标准 |
|----|--------|----------|
| AC-09 | 经营摘要槽 | **无**时间筛。固定今日三卡：换电次数 86、换电人数 18、套餐收入 4,690 元；标签含「今日…（次/人/元）」。点三卡区域进经营统计；经营统计图表默认 **近7日**且独立 |
| AC-123 | 用户数据快照 | 三卡下见「用户数据」9 格（3×3）：今日新增/续费/3天内到期/3天未换电/退租/退电/已逾期/总用户/冻结中。总用户显示 **10** 且副文案 **个人 5 · 渠道 5**；点已逾期进逾期待办 |
| AC-124 | 电池数据快照 | 见「电池数据」1×4：总数 12、使用中 5、空闲 5、**其他 2**（维修中+丢失）；总数=三者之和；点标题进设备统计 |
| AC-10 | 待办空态 | 场景「空宫格」下待办为 0，展示空态文案 |
| AC-11 | 待办队列 | 管理员可见「退款待审」「逾期持电」「渠道商充值申请」及笔数；员工仅见「逾期持电」；点进列表，不是示例占位 |

| AC-13 | placeholder | `status=placeholder` 的模块**不进宫格**（如「示例·经营」不可见）。hash 直链进占位页，正文「本模块暂未开放」，无未上线角标 |
| AC-14 | 角色裁剪 | 管理员可见含 admin 的模块；场景台切员工后仅见含 staff 的模块 |

| AC-16 | 加载失败 | 场景「弱网/失败」下摘要或列表区有错误条 + 可点重试 |

## 7. 不验收（框架期）

- 任何真实业务模块功能与字段正确性（**换电订单、电池详情、运维·站点/电柜、待办/警告、经营统计/设备统计除外**：见下节）
- 推送、扫码硬件、生产登录 SSO
- PC 后台与骑手端改动
