# 决策卡片 #018
- **日期**：2026-09-16 | **阶段**：MVP

## 决策问题
竞品设备「概况」那张宽表，要不要原样塞进运营商 APP「设备统计」？已售、水浸为 0 还要不要占格子？

## 调用的大师视角
- **乔布斯**：手机不能 8 列表格；按现场问题拆成电池 / 柜子 / 仓口 / 告警四类卡片组。
- **唐·诺曼**：已售=0、水浸=0 若隐藏，运营会以为「APP 没这个指标」。0 是信息，不是空态。

## 核心判断
1. 「运营 · 设备统计」承接竞品概况全部统计项。
2. 移动端分组：电池资产、换电柜、电池在线、仓口、在柜/离柜、在仓状态、告警电池、告警电柜。
3. **水浸**即使为 0 也保留。已售已从电池资产移除，见 decision-029。
4. Mock 用本主体台账量级（柜 6 / 电池 12），不搬竞品全网 4403。

## 反方最强论据
项太多，现场只关心离线柜和告警。缓解：告警组用警告底色置顶视觉；失效：若首屏超过 2 次滑动才看到告警，把告警组提到电池资产下面。

## Non-goals
不下钻到电池/电柜列表、不接真实 IoT、不改经营统计、不改工作台摘要槽。

## 下一步验证
设备统计能看见「水浸 0」；告警电柜为 5；按站点仍有未分配行。电池资产口径见 decision-029。

## 知识沉淀
B 端概况 0 值要显式占位；隐藏 0 会被当成功能缺失。
