# decision-067 · 柜外电池作业与远程出电

## 背景

一线需处理用户不在柜边的退电/换电/领电，以及柜机换电中断后的远程出电（旧已还入新未取、开门失败电仍在柜且无还电记录）。

## 决策

1. **入口**：工作台 · 运维 · **柜外电池作业**（`ops.offCabinet`）。搜索用户（手机号/姓名）后按状态展示操作。
2. **柜外退电**（用户持电）：回收 SN（扫码/手输 + 蓝牙校验 Mock）→ 订单 `柜外退电`；用户 **待领取**；电池 **运营商回收**并记操作人。
3. **柜外换电**：A 回收（可只回收稍后再领）→ B 绑定新电；可选用户小程序确认，确认须留痕。
4. **柜外领电**（有套餐、无持电）：绑定新电；可选用户确认留痕。
5. **远程出电**（有套餐）：基于最近柜机换电；换出 SN 已不在格口则拦截；**R1 / R2 标签同时展示**（满足则展示对应标签）；远程开门绑用户 → 订单 `远程出电`。
6. **出电超时**：柜机出电 **5 分钟**未取 → 换电状态 **`出电超时-退电`**（Mock 李骑手样例）；用户可再领或走远程出电。柜外纯回收不单独触发该状态。
7. **体系外电池**：编码不存在则不可回收/绑定。

## 失效条件

蓝牙/扫码与真实 IoT 对接后，校验规则以 BMS/资产台账为准；远程出电若改为骑手端自助，须单独评审权限与留痕。

## 验收

史建国可柜外退电/换电；王骑手可柜外领电；陈晓 R1、李骑手 R2 可远程出电；完成页展示步骤与操作人；用户确认 Mock 出现在步骤列表。
