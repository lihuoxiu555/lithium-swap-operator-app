# decision-074 · 站点删除与列表绑柜

| 项 | 内容 |
|----|------|
| 状态 | 已采纳（原型 V1.107） |
| 日期 | 2026-11-10 |

## 决策

1. **删除站点**：仅 **已停用** 状态；**无在绑电柜**；**非渠道专属**。管理员在详情页操作，二次确认。
2. **列表绑柜**：每站点卡片提供 **绑定电柜**；管理员与员工均可进入（现场运维）。
3. **绑定流程**：扫码（Mock）或手动 SN → 校验：
   - `deviceOwnerId` = 当前运营商（OP-SX）
   - 未绑定其他站点（或为「未分配站点」）
   - `platformRegistered` = true
4. **成功**：写回 `cabinets.js` 站点字段，刷新站点 **柜/电** 计数。

## 失效

若 PC 改为「删除需审批」或绑柜走 IoT 工单，APP 仅保留入口跳转。
