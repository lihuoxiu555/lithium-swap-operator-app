# 决策卡片 #045
- **日期**：2026-09-17 | **阶段**：MVP

## 决策问题
工作台还要不要同时放「经营」和「运营」？电柜管理跟统计还是跟站点？

## 调用的大师视角
- **乔布斯**：经营 / 运营二字几乎同形，两个组名是假分类。合成一组，只留「经营」。
- **唐·诺曼**：电柜的物理对象是站。改站、移柜、通电都围着站点转，应和站点同组，不和报表同组。
- **俞军**：少一个组，找入口的替换成本下降。统计仍在经营，和首页三卡同一心智。

## 核心判断
1. 删除分组「运营」。组枚举：经营 / 运维 / 财务 / 其他。
2. 经营：换电订单、经营统计、设备统计。
3. 运维：站点、电柜管理（站在前、柜在后）。
4. 覆盖 decision-013 的「新开运营组」；页内字段与权限不变。

## 反方最强论据
013 认为三入口应成组，拆开会找不到电柜。缓解：运维只两个宫格，柜在站旁边。失效：若一线口头仍叫「去运营里看电柜」，再在电柜页顶加「原运营入口」一周，不恢复分组。

## Non-goals
不改模块 id / 路由 / 页面字段；不把设备统计塞进运维；不改财务/其他；不改 PC。

## 下一步验证
工作台无「运营」标题。经营下是换电订单、经营统计、设备统计。运维下是站点、电柜管理。
