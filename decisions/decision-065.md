# decision-065 · 工作台「站点繁忙度」独立入口

## 背景

经营统计内已有「站点繁忙度」Tab，但一线调度从工作台进统计页路径长；需独立入口并支持按站点下钻。

## 决策

1. **工作台 · 经营** 新增模块 `biz.siteBusy`「站点繁忙度」，列表 UI **与经营统计·繁忙度 Tab 同组件**，口径不变（decision-057/036）。
2. **列表可点进站点详情**；经营统计繁忙度 Tab 同步可点，进入同一详情页。
3. **详情一期（原型）**：繁忙度 + 三格现场指标（今日换电成功/失败、格口占用、空仓可换/离线柜）+ 高峰/最忙 + **今日 24h 分时条** + 柜机一览 + 调度提示 + 跳转（换电订单/电柜/站点档案）。**不展示等待人数**（见 decision-066）。
4. **待定 / 二期**：近 7 日高峰对比、PC 式统计日回放、排队 ETA；**仍不按站点拆收入**。
5. 数据统计 Tab、经营统计图表/KPI **不变**；不在工作台恢复「经营统计」宫格。

## 支持理由

- **俞军**：调度场景替换成本 = 少 2 次点击 + 直达站点，价值高于多一个宫格。
- **张小龙**：与统计 Tab 同数据，避免两套口径。

## 反对理由

- 与经营统计 Tab 内容重复。缓解：统计页偏看板，工作台入口偏**下钻与跳转**。

## 失效条件

若使用率极低且维护两套入口，可合并为「统计页 Tab + 深链」，撤工作台宫格。

## 验收

管理员：工作台见「站点繁忙度」→ 4 站列表 → 点浦东见详情与分时。员工 13800000005：仅浦东 1 站。
