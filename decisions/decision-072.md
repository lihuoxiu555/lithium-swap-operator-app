# decision-072 · 换电小程序内嵌商户工作台

| 项 | 内容 |
|----|------|
| 状态 | 已采纳（原型 V1.105） |
| 日期 | 2026-11-10 |

## 背景

部分运营商员工习惯在同一换电 **微信小程序** 内处理工单，而非单独安装「锂电快换」独立端。需在 C 端壳上提供员工入口，且与骑手体验可快速切换。

## 决策

1. **端形态命名**：原运营商 H5/APP 原型场景称 **独立端**；同一业务能力在小程序内称 **小程序端**（评审场景台切换，非两套产品）。
2. **入口**：骑手端首页/我的页 **左上角「商户」** → **商户登录**（字段与独立端登录一致）。
3. **登录后**：展示现有 **锂电快换** 四 Tab + 工作台宫格（与独立端同注册表）；小程序场景默认落 **工作台** Tab。
4. **返回 C 端**：商户会话任意页 **右下角悬浮「骑手端」**；点击 **结束 B 端会话** 并回到骑手「我的」（默认 Tab）。
5. **会话互斥**：原型期同一时刻仅一端会话；不模拟双开 Token。

## 反对理由 / 失效条件

- 反对：小程序包体与审核复杂度上升；C/B 同包易混淆权限。
- 失效：若正式环境拆分为两个独立小程序或企微应用，则本决策仅保留 IA 参考，入口文案与路由按正式壳调整。
