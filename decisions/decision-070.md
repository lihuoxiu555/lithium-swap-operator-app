# decision-070 · 渠道商移动端门户（人天池 / 链接类）

**状态**：已采纳  
**日期**：2026-10-29  
**关联**：原型-外卖 · 客户·人天池 / 分销商·链接类；PRD §25

## 背景

运营商 APP 需在同一四 Tab 壳内，为签约渠道提供手机端入口，与 PC 渠道门户能力对齐，但不复制运营商运维/财务全量宫格。

## 决策

1. **身份**：新增 `channelDay`（人天池渠道商）、`channelLink`（推广渠道商）；session 带 `channelId` / `channelName`；演示号与外卖 PC 一致（13900003100 / 13900003201）。
2. **模块注册**：`ch.*` 模块仅对对应 role 可见，分组「渠道」；运营商 `ops.channels` 仍仅 admin/staff。
3. **页面**：`channel-partner.js` 承载渲染；数据统计为渠道 KPI；待办为渠道 Mock 摘要（不接入 Todos.js 审批队列）。
4. **范围**：人天池覆盖额度池五 Tab + 信用 + 结算说明；链接类覆盖链接/购卡/佣金/账户 + 结算说明。PC 二期能力（员工、订单审核等）不做。

## 失效条件

- 渠道账号与运营商账号合并为统一 RBAC 且不再使用独立 role 时，需重构 `modules.js` 与登录选身份流程。
- 真实 API 分账/额度接口上线后，Mock 字段需与 `字段口径-对齐PC一期.md` 渠道端章节同步。
